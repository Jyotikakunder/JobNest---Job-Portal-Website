# JobNest – Job Portal Website

JobNest is a modern and responsive job portal website designed to connect job seekers with employers. It provides an easy-to-use interface for discovering jobs, exploring companies, viewing job details, applying for positions, and managing job postings.

## Features

* 🔍 Job search interface
* 💼 Job listings with filters
* 📄 Detailed job descriptions
* 🏢 Company exploration page
* 👤 Candidate login and signup UI
* 📝 Job application form
* 📎 Resume upload interface
* ⭐ Save/Favorite job UI
* 📊 Employer dashboard
* ➕ Post new job interface
* ✏️ Edit and delete job listing UI
* 📱 Fully responsive design
* 🎨 Clean and professional UI

## Pages

1. **Home** – Hero section, job search, popular categories, featured jobs, and employer CTA.
2. **Jobs** – Browse available jobs with search and filtering options.
3. **Job Details** – View complete information about a selected job.
4. **Companies** – Explore companies and their available positions.
5. **About** – Information about JobNest and its purpose.
6. **Login** – Candidate and employer login interface.
7. **Signup** – Registration interface with candidate/employer role selection.
8. **Employer Dashboard** – View and manage posted jobs.
9. **Post a Job** – Form for employers to create a job listing.
10. **Apply** – Candidate application form with resume and cover letter.

## Design

JobNest follows a clean corporate design using a blue, white, and dark color palette. The website is designed to provide a simple and intuitive experience for both candidates and employers.

The interface is fully responsive and adapts to desktop, tablet, and mobile screen sizes.
